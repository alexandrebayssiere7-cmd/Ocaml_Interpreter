Kawa Playground

Un petit langage objet inspiré de Java. L'interpréteur est écrit en OCaml et compilé en JavaScript : votre code s'exécute directement dans le navigateur.

Structure d'un programme

Un programme contient, dans cet ordre : les variables globales, les classes, puis le bloc main.

var int x;          // 1. variables globales

class point { ... } // 2. classes

main {              // 3. instructions exécutées
  x = 42;
  print(x);
}

Classes et objets

class point {
  attribute int x;
  attribute int y;

  method void constructor(int a, int b) {
    this.x = a;
    this.y = b;
  }

  method int somme() {
    return this.x + this.y;
  }
}
  • new point crée un objet sans appeler de constructeur ; new point(1, 2) appelle constructor.
  • this désigne l'objet courant ; on accède aux attributs avec p.x et on appelle une méthode avec p.somme().
  • Les variables locales se déclarent avec var au début du corps d'une méthode.
  • Une méthode non void doit renvoyer une valeur sur tous les chemins.

Héritage

class triple extends point {
  attribute int z;

  method int somme() {        // redéfinition
    return this.x + this.y + this.z;
  }
}

Une classe hérite des attributs et méthodes de son parent. Un objet triple peut être rangé dans une variable de type point ; l'appel de méthode utilise la version de la classe réelle de l'objet.
